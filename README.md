🧠 프로젝트 여정 (Learning Journey)

이 프로젝트는 하나의 결과물을 만드는 과정이라기보다, "아이디어와 서사가 어떻게 구조화되고 사용자에게 전달될 수 있는가?"라는 질문을 다양한 방식으로 탐구한 과정이었다.

1️⃣ 드라마 텐션 그래프 분석 툴

프로젝트의 시작은 드라마 속 감정의 흐름을 시각화하는 실험이었다.

이야기를 단순한 줄거리로 바라보는 것이 아니라, 긴장감과 감정 변화가 어떤 패턴을 통해 형성되는지 분석하고자 했다.

탐구한 주제

- 감정 곡선 시각화
- 서사 구조 분석
- 이야기의 정량적 표현

---

2️⃣ 뮤지컬 넘버 텐션 그래프 툴

이후에는 분석 대상을 공연예술로 확장하였다.

뮤지컬 넘버가 작품 전체의 감정선 속에서 어떤 역할을 수행하는지 시각적으로 표현하고자 하였으며, 이야기와 감정의 흐름을 보다 입체적으로 이해하는 방법을 탐구했다.

탐구한 주제

- 공연 콘텐츠 분석
- 감정 흐름 시각화
- 서사와 음악의 관계

---

3️⃣ 인스타 매거진 자동 생성 툴

앞선 단계가 콘텐츠를 분석하는 과정이었다면, 이 단계에서는 콘텐츠를 생성하는 방향으로 관심이 이동했다.

하나의 아이디어를 매거진 형식의 콘텐츠로 재구성하는 실험을 진행하며, 정보가 어떤 구조를 통해 전달되는지 탐구하였다.

탐구한 주제

- 콘텐츠 자동 생성
- 정보 구조화
- 시각적 스토리텔링

---

4️⃣ 맞춤형 관광 프로그램북 생성기

다음 단계에서는 생성된 콘텐츠를 사용자 맞춤형 경험으로 발전시키고자 했다.

사용자의 조건과 관심사에 따라 서로 다른 결과물을 제공하는 시스템을 설계하며, 콘텐츠 생성과 개인화의 결합 가능성을 실험했다.

탐구한 주제

- 개인화 콘텐츠
- 사용자 경험 설계
- 정보 큐레이션

---

5️⃣ Murder for You

최종 프로젝트에서는 관심의 중심이 콘텐츠 자체에서 "서사 경험"으로 이동했다.

Murder for You는 피해자, 용의자, 증거, 사건 배경 등의 요소를 조합하여 새로운 추리 사건을 생성하는 인터랙티브 웹 애플리케이션이다.

사용자는 단순히 결과물을 소비하는 것이 아니라, 제공된 정보를 바탕으로 추론하고 선택하며 이야기 속에 직접 참여하게 된다.

이 프로젝트는 한 학기 동안 진행한 실험들의 연장선상에서, 분석 → 생성 → 개인화 → 참여라는 흐름을 통합하여 구현한 결과물이라고 볼 수 있다.

탐구한 주제

- 인터랙티브 서사 생성
- 절차적(Procedural) 콘텐츠 생성
- 사용자 참여형 스토리텔링
- AI 기반 창작 시스템의 가능성

---

💡 핵심 인사이트

한 학기 동안의 실험을 통해 얻은 가장 큰 결론은, AI 기반 창작에서 중요한 것은 단순한 생성이 아니라 구조화와 경험 설계라는 점이었다.

콘텐츠는 정보를 만들어내는 것만으로 완성되지 않는다. 사용자가 그것을 어떻게 이해하고, 탐색하고, 참여하는가에 따라 전혀 다른 경험이 된다.

Murder for You는 이러한 고민의 결과로 탄생한 프로젝트이며, 생성형 시스템이 단순한 자동화 도구를 넘어 새로운 서사 경험을 제공할 수 있다는 가능성을 보여주고자 했다.
