# 🎤 Voice Creative Copilot

아이디어를 음성으로 입력하면 다양한 콘텐츠 형태(웹툰, 카드뉴스, 영상 등)로 구조화해주는 AI 기반 창작 보조 도구입니다.

---

## 🧭 프로젝트 개요

이 프로젝트는 단순한 “AI 콘텐츠 생성기”가 아니라,  
**아이디어가 콘텐츠로 변환되는 과정을 탐구하기 위한 실험적 도구**입니다.

처음에는 특정 기능을 구현하는 것이 목표였지만,  
점차 다음 질문으로 확장되었습니다:

> "사람의 창작 아이디어는 어떻게 구조화되고 콘텐츠로 변환될 수 있는가?"

---

## 🧠 프로젝트 여정 (Learning Journey)

이 프로젝트는 한 번에 완성된 결과물이 아니라,  
하나의 질문을 다양한 방식으로 반복 탐구한 과정입니다.

### 1️⃣ 드라마 텐션 그래프 분석 툴
- 드라마의 감정 구조를 시각화하려는 시도
- 창작물을 “정량적 구조”로 분석할 수 있는지 탐구


---

### 2️⃣ 뮤지컬 넘버 텐션 그래프 툴
- 음악/공연 콘텐츠로 확장
- 감정 흐름을 시각적으로 표현하는 방법 실험

---

### 3️⃣ 인스타 매거진 자동 생성 툴 (실패)
- 콘텐츠 생성 자동화 시도
- 구조화와 디자인 자동화의 한계를 경험

---

### 4️⃣ 맞춤형 관광 프로그램북
- 사용자 기반 콘텐츠 개인화 실험
- 기능은 동작했지만 결과물의 차별성이 부족함

---

### 5️⃣ Voice Creative Copilot (현재 프로젝트)
- 음성을 기반으로 아이디어 입력
- 아이디어를 콘텐츠 형태로 구조화 (웹툰 / 카드뉴스 / 영상 등)
- 창작 초기 단계 자동화를 목표로 하는 통합 프로젝트

---

## ⚠️ 기술적 이슈 및 한계

### API 연동 문제
- OpenRouter API 사용 중 **크레딧 부족으로 인한 요청 실패(401 Unauthorized)** 발생
- 실제 AI 응답은 제한된 상태

👉 현재는 데모 구조 기반으로 UI와 흐름을 중심으로 구현됨

---

## 💡 핵심 인사이트

이 프로젝트를 통해 얻은 핵심 결론은 다음과 같습니다:

- 아이디어는 “생성”보다 “구조화”가 더 중요하다
- 실패는 기능의 끝이 아니라 다음 실험의 시작점이다
- AI 도구의 핵심은 결과물이 아니라 “변환 과정”이다

---

## 🛠 사용 기술

- HTML / CSS / JavaScript
- Web Speech API (음성 입력)
- OpenRouter API (AI 모델 연결 시도)
- Prompt Engineering 기반 콘텐츠 구조화
